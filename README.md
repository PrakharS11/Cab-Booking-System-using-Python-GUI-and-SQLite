# Cab Booking System using Python GUI and SQLite

## Overview
This project is a desktop-based cab booking application developed using Python Tkinter and SQLite. The system provides separate portals for admin and users, allowing cab management and booking functionality.

## Features

### User Features
- User sign in and sign up
- Forgot password screen
- Search cab by type
- Enter pickup and drop location
- Confirm cab booking
- Help and support module

### Admin Features
- Admin login
- Add cab details
- Search cab details
- View cab information from database

## Technologies Used
- Python
- Tkinter
- SQLite
- SQL

## Database Details
The project uses an SQLite database file named `data1base.db`.

Main table used:

`avi`

Columns:
- car_id
- car_no
- car_type
- car_name
- car_rate
- car_driver
- car_driverno
